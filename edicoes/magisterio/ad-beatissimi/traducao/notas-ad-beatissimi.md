# Notas do tradutor: Ad Beatissimi Apostolorum (Bento XV, 1914)

Texto de base: o latim do site da Santa Sé. O PDF das _Acta_ (AAS 6, 1914, p. 565-581) no vatican.va
é só o texto do OCR, sem a imagem da página, e tem os mesmos erros do site: não serviu para conferir.
Por isso só se corrigiu o erro evidente, pela gramática e pelo sentido; numeração dos parágrafos pela
versão inglesa do site (§ 2-33; o primeiro não leva número). 69 blocos, 37 notas.

## Correções no original
- Letras separadas ou juntas: «ob versaretur», «i am» (3 vezes), «re vocandis», «u n um», «t um»
  (cleri), «t a n t um», «impediment um», «solat i um», «t am» (2), «h a r um», «libert a t e»,
  «atro citati», «inter ceptis», «itaomnes», «hac illae» → «hac illac», «abhorre ant», «pestifera, lues».
- Letras trocadas: «veb» → «vel»; «exprdbraverint» → «exprobraverint»; «iii hominibus» → «in»;
  «infiammatimi» → «inflammatum»; «excita tam» → «excitatam»; «conspirations» → «conspiratione»;
  «intemperante» → «intemperantia»; «contemnenent» → «contemnerent»; «monstruos errores» →
  «monstruosi»; «amrmaveris» → «affirmaveris»; «Bes enim» → «Res»; «debe» → «debet»; «Eomanus» →
  «Romanus»; «numo quam» → «numquam»; «fraternitate studium» → «fraternitatis»; «Innati» →
  «Inflati»; «nascituri agum» → «nascitur legum» (o OCR das _Acta_ lê «nascitur iagum»).
- Gramática: «tamquam limina» → «limine»; «descendisse ut» → «descendisset»; «maturarunt» →
  «maturarent» (depois de «obsecravimus, ut»); «impensissimo rogavit» → «impensissime»; «Alteram
  disámus» → «dicimus» (a inglesa: «we declare»).
- Conjectura: «virtutis ac oralitatis» → «immortalitatis» (§ 19; italiano e francês do site:
  «indefectibilidade»). É a decisão de `revisao-ad-beatissimi.json`.
- Nota 25: «Hebr. XIII, 13» → «XIII, 14» (o versículo citado é Hb 13,14).
- Mantido: «nos tum dicit inter nos esse, tum suos appellat» (§ 6; «tum… tum»), confirmado no OCR
  das _Acta_.

## Termos
- ordines civium: «classes» (dos cidadãos); cessationes ab opere: «greves».
- appellationes (§ 24, os rótulos «integrista», «modernista»): «apelativos»; apposita: «qualificativos».
- «Christianus mihi nomen, catholicus cognomen»: «Cristão é o meu nome, católico o meu sobrenome».
- Inácio (nota 33) e Cipriano (nota 36): títulos em português.
