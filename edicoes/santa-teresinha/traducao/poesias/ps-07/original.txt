# titulo: Le silence est le doux langage
# sigla: PS 7
# data: juin ? 1897
# destinatario: une carmélite inconnue
# epigrafe: Voilà mon commandement : c'est que vous vous entr'aimiez, comme je vous ai aimés !... St Jean XVI-12.
# fonte: https://archives.carmeldelisieux.fr/archive/ps7/
# nota: conferido com o site antigo (archives-carmel-lisieux.fr/carmel/index.php/ps-7); o texto dos versos é o mesmo nos dois (o antigo traz «nous» minúsculo no v. 8). Nenhum dos dois indica ária. A remissão da epígrafe é a que Teresa escreveu (XVI-12); o versículo é Jo 15,12.

Le silence est le doux langage
Des anges, de tous les élus.
Il doit être aussi le partage
Des âmes s'aimant en Jésus.

Ce n'est qu'au sein des sacrifices
Que l'on peut s'aimer au Carmel.
Un jour, enivrées de délices
Nous nous aimerons dans le Ciel.
