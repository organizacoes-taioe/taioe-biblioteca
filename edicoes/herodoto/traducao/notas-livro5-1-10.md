# Notas: livro V, 1–10

## Nomes e termos
- Megabazo, os perintios e Perinto, os peônios do Estrímon, os trácios, os getas «que se creem imortais» (como no
  livro IV, 93), os trausos, os crestoneus, os sigines, os ênetos do Adriático, os lígures de Massália, os cipriotas,
  o Istro, a Ursa (ἡ ἄρκτος, o norte).
- μουνομαχίη → «combate singular»; παιωνίζειν → «cantar o peã»; στίζειν → «tatuar» (como em 35); ἀργός → «à toa».
- _sigines_ (9.3): a palavra fica em itálico, com a explicação dele (os comerciantes, para os lígures; as lanças,
  para os cipriotas).

## Passagens
- 1.2: a condição do oráculo segue a ordem do grego (se gritarem o nome, atacar; se não, não atacar).
- 1.3 «agora é a nossa vez»: literalmente «agora é obra nossa».
- 5.1: Godley imprime «πολλά,·», erro tipográfico; o grego desta edição traz πολλάς (ver `original/LEIAME.md`), e
  a tradução, «muitas mulheres», não muda.
- 8.1 κατὰ λόγον μουνομαχίης → «os maiores prêmios são para o combate singular» (Godley entende o mesmo).
- 10.1 δύσριγα → «não suportam o frio».
