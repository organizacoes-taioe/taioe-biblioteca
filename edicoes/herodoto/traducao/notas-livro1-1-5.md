# Notas: livro I, 1–5

## Nomes e termos
- ἱστορίης ἀπόδεξις (1.0) → «a exposição da investigação» (ἱστορίη é a pesquisa, o inquérito; ver `revisao.json`).
- οἱ λόγιοι (1.1) → «os eruditos» (os que guardam as histórias de um povo); Ἐρυθρὴ θάλασσα → «o mar que se chama
  Eritreu» (para Heródoto, o mar ao sul da Ásia, não só o nosso Mar Vermelho: deixei o nome grego aportuguesado).
- Ἰοῦς, Ἴναχος → Io, Ínaco; Αἶα → Ea; Φᾶσις → Fásis; Κόλχοι → colcos; Ἀλέξανδρος ὁ Πριάμου → «Alexandre, filho de
  Príamo» (Páris; Heródoto sempre o chama Alexandre: manter).
- μακρὴ νηῦς (2.2) → «navio de guerra» (o navio longo, de remo, por oposição ao «redondo», de carga).
- ναύκληρος (5.2) → «capitão do navio» (o dono e comandante).
- ἀδίκημα, ἀδικίη → «agravo»; δίκας διδόναι/αἰτέειν → «dar/pedir reparação».
- σωφρόνων (4.2) → «homens sensatos».

## Passagens
- 1–5 são quase todos discurso indireto (acusativo com infinitivo, «dizem os persas que…»): traduzi em narrativa
  direta com «dizem» de tempos em tempos, onde o grego o repete, para não cansar o leitor.
- 2.1 ἴσα πρὸς ἴσα σφι γενέσθαι → «estavam quites».
- 3.2 τοὺς δέ: os troianos, que o grego não nomeia → «os outros».
- 4.4 τὸ Ἑλληνικόν → «o povo grego».
