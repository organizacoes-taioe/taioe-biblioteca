# Notas do tradutor: livro II, capítulos 13–21 (lote 1)

Blocos iguais ao original, marcas no lugar. Grep de mesóclise sem resultado.

## Escolhas

- II,13–14 **jugo** (o que se tira da meditação) → «suco»; **empapamiento** → «encharcamento»; **embelesamiento** →
  «embevecimento».
- II,14,2 **allegada el agua** → «a água ajuntada»; **arcaduces** → «canais».
- II,14,6 **seguirse hía / faltarle hía** → «seguiria daí / haveria por força de faltar» (sem mesóclise); **actuadas**
  → «em ato».
- II,14,8–9 **de más tomo / tomo de cuerpo** → «de mais vulto / vulto de corpo»; **motas** → «partículas»;
  **polvitos** → «grãozinhos de pó».
- II,14,11 **Recordé** (= despertei) → «Despertei»; **solamente sabe a Dios** → «só sabe de Deus».
- II,15,1 **aprovechantes** → «aproveitados» (termo fixo).
- II,16,3 **los cuernos con que dijo había de destruir a los asirios** (1 Rs 22, onde são os sírios): traduzido como
  está, «os assírios».
- II,16,9 **aparecerle he** → «hei de aparecer-lhe» (sem mesóclise).
- II,16,10 **vidriera** → «vidraça»; a frase «no las puede resistir la voluntad negativa con resignación…, sino sola
  la impureza» ficou ao pé da letra.
- II,16,15 **candela / candelero** → «candeia / castiçal».
- II,17,5 **toda carne es insipiente** → «toda carne é insípida» (o adágio _desipit_).
- II,17,6 **pequeñuelo** → «pequenino».
- II,18 **término** (o modo do confessor) → «maneira»; **lleno** (satisfação) → «satisfação»; **hacer presa** →
  «prender-se»; **a carga cerrada** → «de olhos fechados»; **almas bobas** → «almas simplórias»; **no hilemos tan
  delgado** → «não fiemos tão fino».
- II,18,4 «el vicio de gula espiritual, y de los otros seis»: remete à _Noite_ (I, os sete vícios capitais dos
  principiantes); traduzido como está.
- II,19,2 a frase «pudieran errar mucho, pues no eran de aquel tiempo, los que le vieran morir…» está truncada no
  original; traduzida pelo sentido, sem acréscimo.
- II,19,7 **alucina** → «se ofusca»; **vuelve por el pueblo** → «toma a defesa do povo»; **cuchillo** (_gladius_)
  → «espada»; **Enseñorearse ha / desmenuzarlas has / dárseles ha** → «Há de dominar / hás de despedaçá-las / há de
  ser dado».
- II,19,9 **castillo de Emaús** → «povoado de Emaús» (_castellum_ = aldeia); **insipientes** → «insensatos».
- II,19,11 **no se abrevie** → «não se estreite»; **impóngale en que** → «ensine-o a».
- **embestir** (a notícia que investe na alma) → «investir».
