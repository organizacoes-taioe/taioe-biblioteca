# Vida de São Bento (Diálogos, livro II): convenções da tradução

Texto: PL 66 (Migne), em `original/parte-1.txt` a `parte-4.txt`. A tradução fica em `traducao/` com o
mesmo nome e **os mesmos blocos, na mesma ordem** (um bloco traduzido por bloco do original, separados por
linha em branco). Cabeçalho da tradução: só `# titulo: Vida de São Bento, …`.

## Forma
- `## Praefatio` → `## Prólogo`; `## 3. De vase vitreo…` → `## 3. O vaso de vidro quebrado pelo sinal da cruz`
  (título curto, sem «De…», em português corrente). A marca `[II.n]` fica igual, no começo do 1º parágrafo.
- Quem fala: `_Gregorius._` → `_Gregório._`; `_Petrus._` → `_Pedro._` (em itálico, como no original).
- Fala direta entre aspas curvas “…”; dentro delas, ‘…’. Gregório trata Pedro por **tu**; Bento fala aos
  monges por **vós**; Deus em oração, **tu** (Tu com maiúscula só no início de frase).
- Citações da Escritura: traduzidas do latim de Gregório (não de uma Bíblia moderna); a referência entre
  parênteses passa às abreviaturas usuais no Brasil, numeração da Vulgata: (Luc. XV, 17) → (Lc 15,17);
  (II Cor. XI, 22) → (2Cor 11,22); (Psal. XC, 13) → (Sl 90,13); (Act. IX) → (At 9); (Matth.) Mt; (Joan.) Jo;
  (IV Reg.) 2Rs (4Rs na Vulgata: usar «2Rs»); (III Reg.) 1Rs; (Eccli.) Eclo; (Rom.) Rm; (I Cor.) 1Cor.
- Português do Brasil, fiel ao sentido, sem acréscimos nem explicações; frases longas podem ser divididas
  quando o português pedir. **Nunca mesóclise.**

## Termos fixos
| latim | tradução |
|---|---|
| vir Dei | o homem de Deus |
| venerabilis vir / venerabilis Benedictus | o venerável homem / o venerável Bento |
| vir vitae venerabilis | um homem de vida venerável |
| pater (do mosteiro) / abbas | o pai / o abade (minúsculas) |
| pater (Bento, chamado pelos monges) | o pai |
| frater, fratres | irmão, irmãos |
| monachus; monasterium; cella; specus | monge; mosteiro; cela; gruta |
| congregatio | comunidade |
| conversatio | vida (monástica); «sanctae conversationis habitus» = o hábito da vida santa |
| regula | a Regra (maiúscula quando é a de Bento) |
| virtus (= milagre, poder) | milagre (quando é feito); poder (quando é a força) |
| signum; miraculum; prodigium | sinal; milagre; prodígio |
| spiritus prophetiae | o espírito de profecia |
| antiquus hostis; malignus spiritus; daemon | o antigo inimigo; o espírito maligno; o demônio |
| omnipotens Deus | Deus todo-poderoso |
| oratio; orare | oração; orar |
| mens | mente (ou «espírito», quando «mente» soar estranho; anotar) |
| praepositus | o prior |
| castrum | o castro (de Cassino) |
| solidus | soldo (moeda) |
| Petre (vocativo) | Pedro |
